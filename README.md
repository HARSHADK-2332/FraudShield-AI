# 🛡️ FraudShield AI

AI-Powered Fraud Detection System for suspicious URLs, fraud calls, and scam messages.

## 🚀 Live App

👉 **Use FraudShield AI:** https://fraudshield-ai-hk.streamlit.app/

## 🔍 Features

- 🔗 Suspicious URL detection
- 📞 Fraud call analysis
- 💬 Fraud message analysis
- 🤖 AI fraud-safety assistant
- 📋 Scan history
- 🧠 Rule-based detection + ML risk scoring
- 🌈 Cyber-security themed interface

## 🛠️ Tech Stack

- Python
- Streamlit
- Scikit-learn
- Plotly
- SQLite
- Joblib

## ⚠️ Note

FraudShield is a safety-assistance project. Detection results are risk indicators and should not be treated as a guarantee that a URL, call, or message is safe.
